# TypeFly: Learn & Play

Build a complete, polished, cozy, and playful typing-skills website called “TypeFly.” The main experience should be a fun Typing Bird game where users type the words shown on screen to make the bird fly. Include 1-minute, 2-minute, and 5-minute tests, 3 hearts/lives, combo streaks, real-time WPM and accuracy, mistake tracking, smooth bird movement/attack-style animations, sound effects, and a mute button. After each test, show a polished results screen with WPM, accuracy, errors, characters/words typed, and performance summary.

Also create a Beginner Mode for users who are new to typing, with simple text practice, typed characters becoming highlighted/bold, real-time accuracy and speed tracking, and an interactive keyboard finger-placement guide showing which finger should press each key.

Make the entire UI feel like a modern casual game rather than a traditional educational website. Use a beautiful, friendly color palette, smooth animations, satisfying feedback, responsive design, and create the visual assets and sound effects within Lovable—no external custom assets required.

Include user authentication/profile basics, a simple premium/payment page, and integrate Razorpay in TEST MODE using environment variables for the test keys. Do not process real payments.

Also include essential website pages: Home/Game Lobby, Beginner Mode, Typing Bird, Results, Pricing/Premium, About, Contact, Privacy Policy, Terms of Service, and Cookie Policy. Add a clean footer with links to the legal pages.

Prioritize a fully functional typing engine, polished Typing Bird gameplay, responsive UI, and a smooth user experience. Keep the project focused and avoid unnecessary extra features.
